# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: open the
[Security tab](https://github.com/bughatti/voidscout-uploader/security) of this repository and
choose **Report a vulnerability**. Only the maintainer can see the report.

Include what you found, the version you tested, and steps to reproduce it. You
should get a first response within a week.

## Supported versions

Only the latest release receives security fixes. Upgrade first and check
whether the problem is still there.

## Scope

In scope: the code in this repository and the uploader binaries published on this repository's Releases page, including the self-update path that installed uploaders use to fetch new versions.

Out of scope: vulnerabilities in third-party dependencies or the Go standard
library that this project does not make exploitable. Report those upstream.
